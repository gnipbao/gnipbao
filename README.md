## 🧠 About Me

> **I design AI workflows that turn messy ideas into executable systems.**

Hi, I'm **gnipbao** — an AI builder focused on **Agent Skills, Codex workflows, automation systems, creative tooling, and knowledge engineering**.

I like building things that are not just demos, but **repeatable production-style workflows**:

- 🧩 **AI Skill Systems** — turn knowledge, SOPs, and creative methods into reusable agent skills  
- 🎬 **Video Automation** — Codex + scripts + rendering pipelines for content generation  
- 📊 **PPT / Visual Storytelling** — story-first presentation workflows and deck QA  
- 🧠 **Knowledge OS** — structured learning, notes, prompts, agents, and operating systems  
- ⚙️ **Developer Automation** — tools that collect, route, transform, and verify information
